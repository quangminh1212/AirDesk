# AirDesk

AirDesk is a flight-search and fare-monitoring project in early development.

## Status

This repository has just been initialized. It does not yet contain a crawler,
live fare data, or provider integrations. The first feature and its data sources
still need an approved design.

## Data access principles

- Use sources that explicitly permit automated access.
- Do not bypass logins, CAPTCHAs, or bot protections.
- Show where a fare came from and when it was observed. Treat displayed fares as
  indicative until rechecked with the provider.

## Development

Setup, run, and verification instructions will be added with the first approved
feature.
